# STEMP Tools UI defaults

The user requires all new and updated pages to be tight, clean and compact by default. Do not wait for a separate request to reduce spacing.

- Prefer dense aligned rows over large cards or generous empty space.
- Use roughly 11–12px body text in data-heavy views, 4–6px vertical row padding, small icons and compact controls.
- Keep page headings, status lines, summary metrics and filters compact.
- Put secondary information in expandable details. Expanded details must also use compact spacing.
- Preserve readable labels, keyboard focus, responsive behavior and usable controls; allow long names to wrap without overlap.
- Match the current theme and avoid changing unrelated pages when fixing one view.
